중1 국어 문법 미션 - Streamlit 배포 파일

파일 구성
1. app.py
2. requirements.txt

배포 순서
1) GitHub에서 새 Repository를 만듭니다.
2) app.py와 requirements.txt를 같은 저장소 최상단에 업로드합니다.
3) Streamlit Community Cloud(share.streamlit.io)에 로그인합니다.
4) Create app / Deploy a public app from GitHub를 선택합니다.
5) Repository를 선택하고 Main file path를 app.py로 지정합니다.
6) Deploy를 누릅니다.

현재 포함된 활동
- 파생어 찾기 + 형태소 분석 + 품사
- 문장에 쓰인 모든 단어의 품사
- 자립/의존 형태소 분류
- 실질/형식 형태소 분류

문장
먹구름이 가득 낀 하늘은 늘 철수가 공포에 잡아먹히게 하였다.
